❖ 0-1背包 二维动态规划推演系统

任务简报

旅行者有一个最多装 M 公斤的背包和 N 件物品。每件物品重量为 Wi，价值为 Ci。求背包能获得的最大总价值。

样例输入：
10 4 (M=10, N=4)
2 1   3 3   4 5   7 9

标准二维状态转移方程

定义 dp[i][j]：前 i 件物品在剩余容量为 j 时的最大价值。

放不下 (j < Wi)：继承上一行同列的成果（放弃当前物品）
dp[i][j] = dp[i - 1][j]
放得下 (j ≥ Wi)：在“不放”与“选择放入”中取最大值
dp[i][j] = max( dp[i - 1][j], dp[i - 1][j - Wi] + Ci )

竞赛标准二维 C++ 代码 (完全对应图形矩阵)

此代码的逻辑和循环顺序与上方可视化演示完全严格一致。前置全局声明静态数组，天然初始化 dp[i][0] = 0 和 dp[0][j] = 0。 

#include <iostream>
#include <algorithm>
using namespace std;

int m, n;
int w[35], c[35];
int dp[35][205]; // 二维决策矩阵

int main() {
    // 读入背包容量与物品数量
    cin >> m >> n;
    for (int i = 1; i <= n; i++) {
        cin >> w[i] >> c[i];
    }

    // 正序遍历物品 i，正序遍历容量 j 
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (j < w[i]) {
                // 放不下：直接继承上一行的成果
                dp[i][j] = dp[i - 1][j];
            } else {
                // 放得下：在“放弃当前物品”和“腾出空间买入”之间取最大值
                dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w[i]] + c[i]);
            }
        }
    }

    // 右下角终点即为最大总价值
    cout << dp[n][m] << endl;
    return 0;
}
